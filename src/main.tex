\chapter*{Cómo usar este libro}
\addcontentsline{toc}{chapter}{Cómo usar este libro}
Este libro está concebido como una colección de problemas para el aprendizaje y la práctica de las ecuaciones diferenciales, con especial atención a la modelización y a sus aplicaciones en ciencias e ingeniería. Cada capítulo incluye recordatorios breves y problemas ordenados para practicar después de estudiar el tema. No es necesario resolverlos todos de una vez.

Intenta primero formular el problema, anticipar el comportamiento de la solución y justificar tus decisiones. Comprueba después la ecuación, las condiciones y, cuando corresponda, las unidades y la interpretación. Las respuestas, las pistas y las soluciones se consultan en secciones separadas mediante enlaces.

Todos los ejercicios forman parte del conjunto principal del libro (Core). La dificultad se indica como Básico, Intermedio, Avanzado o Reto; una mayor dificultad no implica que se trate de un tema de ampliación. Las marcas Oral, Croquis a mano y Representación recogen demandas del enunciado. Puedes ensayar individualmente las explicaciones orales.

La numeración capítulo.ejercicio organiza la lectura. Las soluciones de consulta muestran el razonamiento completo de una selección representativa. En los problemas de modelización, una respuesta depende de las hipótesis que hayas declarado.
