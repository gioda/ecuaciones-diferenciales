\(0<x<1\), con las condiciones de cada apartado. Se buscan autofunciones no idénticamente nulas.

\begin{enumerate}[label=(\alph*),ref=\alph*,leftmargin=*]
\item \(y'(0)=0,\ y(1)=0\).
\item \(y'(0)=0,\ y'(1)=0\).
\end{enumerate}
